# Инструкция владельца компании — платформа КЕРН

Это руководство — для владельца компании: вы заводите участки, бригады,
сотрудников и логины, назначаете роли и видите аналитику по всей
компании.

## 1. Как войти

При первом запуске платформы для входа используется демонстрационный
логин, который выдаёт команда, настраивавшая платформу (e-mail и
временный пароль). Обязательно смените пароль на свой, как только войдёте
— в этой версии интерфейса смена пароля через личный кабинет ещё не
реализована, если понадобится сменить пароль после начала работы,
обратитесь к команде технической поддержки платформы.

## 2. Как завести участок

1. Откройте раздел **«Участки»**.
2. Нажмите **«Новый участок»**.
3. Заполните форму:
   - **«Название»** — например, «Скв. №14, Восточный»;
   - **«Код участка»** — короткий буквенно-цифровой код, например
     `SITE-14`;
   - **«Тип работ»** — Геология, Геотехника, Бурение или Смешанный;
   - **«Клиент»** — необязательно;
   - **«Бюджет, ₽»** — необязательно, но без него на странице
     «Аналитика» по этому участку не получится увидеть план по бюджету
     (только факт);
   - **«Описание»** — необязательно.
4. Нажмите **«Создать участок»** — вас перенесёт на страницу этого
   участка, где сразу можно добавить бригады.

Изменить эти данные позже, а также посмотреть их — можно на странице
самого участка (**«Редактировать»** в правом верхнем углу).

## 3. Как добавить бригаду (с учётом вахтового графика)

1. Откройте нужный участок в разделе **«Участки»**.
2. В блоке **«Бригады»** нажмите **«Новая бригада»**.
3. Заполните:
   - **«Название бригады»**;
   - **«График»** — выберите один из трёх вариантов: **Вахта 15/15**,
     **Вахта 30/30** или **Плавающий график** (свободный текст здесь не
     принимается — это намеренное ограничение, чтобы графики были
     сопоставимы между бригадами);
   - **«Бригадир»** — выберите логин уже существующего пользователя
     платформы. Если нужного логина ещё нет в списке, появится
     подсказка «Пока нет ни одного логина для назначения бригадиром —
     добавьте на странице «Команда»» — сначала создайте логин будущему
     бригадиру (раздел 5 ниже), потом возвращайтесь сюда. Можно также
     оставить бригаду без бригадира и назначить его позже.
4. Нажмите **«Создать бригаду»**.

Изменить название, график или бригадира уже созданной бригады можно
значком карандаша на карточке бригады; удалить бригаду можно только если
в ней не осталось ни одного сотрудника.

## 4. Как добавить сотрудника

Сотрудники заводятся не отдельной страницей, а прямо на карточке бригады,
в которую их нужно включить:

1. Откройте участок → нужную карточку бригады.
2. Если в компании ещё нет ни одной должности — сначала зайдите в раздел
   **«Должности»** и заведите хотя бы одну (без должности у сотрудника
   не будет базовой ставки, и его нельзя будет добавить).
3. На карточке бригады нажмите **«Добавить сотрудника»**.
4. Укажите **ФИО сотрудника** и выберите **должность** из списка.
5. Нажмите **«Сохранить»**.

## 5. Как создать логин для нового человека и назначить роль

1. Откройте раздел **«Команда»**.
2. В форме **«Добавить логин»** заполните:
   - **«Имя»** — полное имя человека;
   - **«E-mail»** — на него человек будет входить;
   - **«Временный пароль»** — минимум 8 символов, сообщите его человеку
     лично и попросите сменить при первой возможности (самостоятельная
     смена пароля в интерфейсе пока не реализована);
   - **«Роль»** — выберите нужную роль из списка (например, «Бригадир»,
     «Руководитель участка», «Расчётчик / бухгалтер» и т. д.).
3. **Если выбрана роль «Руководитель участка»** — под формой сразу же
   появляется дополнительный блок **«Доступные участки»** со списком
   галочек по всем участкам компании. Обязательно отметьте хотя бы один
   участок — если оставить список пустым, появится предупреждение «Без
   выбранного участка эта роль не увидит ни одного объекта», и
   пользователь с этой ролью действительно не увидит вообще ничего, пока
   вы не назначите ему участок. Остальным ролям (Бригадир, Расчётчик и
   т. д.) этот блок не показывается — их область видимости определяется
   иначе (по бригаде или по всей компании).
4. Нажмите **«Добавить»**.

Чтобы позже поменять роль, список доступных участков, имя или временно
отключить доступ человеку без удаления его истории — нажмите значок
карандаша рядом с его именем в списке, поправьте поля (включая тот же
блок «Доступные участки», если меняете роль на «Руководитель участка») и
нажмите **«Сохранить»**. Галочка **«Активен»** отключает вход для
человека, не стирая записи о том, что он вносил или согласовывал раньше.

## 6. Как посмотреть общую аналитику по компании

1. Откройте раздел **«Аналитика»**.
2. Выберите период сверху (День / Неделя / Месяц / Квартал / Год / Свой
   период) и, если нужно, конкретный участок — либо оставьте «Все
   участки», чтобы увидеть сводку по всей компании сразу.
3. Вверху — суммарные часы, фонд оплаты труда (ФОТ), метраж и стоимость
   метра бурения за выбранный период.
4. Ниже — график ФОТ по периодам.
5. В самом низу — блок **«Бюджет участков: план vs факт»** по каждому
   участку компании (у вас, в отличие от руководителя участка, видны все
   участки без исключения).

Учтите: в цифры аналитики попадают только табели в статусах
**«Подтверждён»** и **«Заблокирован»** — то, что бригадиры ещё не внесли
или руководители участков ещё не согласовали, здесь не отображается.

## 7. Как архивировать участок

1. Откройте нужный участок в разделе **«Участки»**.
2. В правом верхнем углу нажмите **«Архивировать»**.
3. Подтвердите действие во всплывающем окне («Архивировать участок
   «…»? Он пропадёт из общего списка, но все данные по нему
   сохранятся»).

Архивированный участок пропадает из вкладки **«Активные»** на странице
«Участки», но не удаляется — его можно найти на вкладке **«Архив»**, а
все его табели, бригады и история расчётов остаются доступны. Чтобы
вернуть участок обратно, откройте его в архиве и нажмите **«Вернуть из
архива»**.

## Если что-то пошло не так

- **Не могу назначить бригадира при создании бригады** — сначала
  создайте логин для этого человека на странице «Команда» (раздел 5), с
  любой подходящей ролью; бригаду можно оставить временно без бригадира
  и вернуться к назначению позже.
- **Руководитель участка жалуется, что не видит свой объект** — откройте
  его логин на странице «Команда», проверьте роль «Руководитель
  участка» и убедитесь, что нужный участок отмечен галочкой в блоке
  «Доступные участки».
- **Забыт пароль сотрудника, а самостоятельно сменить его нельзя** — в
  этой версии платформы нет ни формы «забыли пароль», ни возможности
  сбросить чужой пароль через страницу «Команда» — обратитесь в
  техническую поддержку платформы для решения на уровне сервера.
